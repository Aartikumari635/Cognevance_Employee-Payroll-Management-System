# Employee Payroll Management System

## Project Overview

The Employee Payroll Management System is a Java desktop application developed using Java Swing and MySQL. It helps manage employee information, payroll processing, and salary reports.

## Technologies Used

* Java
* Java Swing
* MySQL
* JDBC
* NetBeans IDE

## Features

* Login authentication
* Employee registration
* Employee details management
* Payroll processing
* Salary report module
* MySQL database connectivity

## Project Structure

* `src/` – Java source code and application images
* `nbproject/` – NetBeans project configuration
* `Screenshot/` – Application screenshots
* `build.xml` – Build configuration
* `manifest.mf` – Application manifest

## Setup Instructions

1. Install the JDK, NetBeans IDE, and MySQL Server.
2. Clone or download this repository.
3. Open the project in NetBeans.
4. Create a MySQL database named `payroll`.
5. Create the required tables using the SQL script.
6. Configure the database username and password in `Connect.java`.
7. Add the MySQL JDBC Connector to the project if required.
8. Build and run the application in NetBeans.

## Project Workflow

1. The user logs in to the application.
2. The Home page provides access to employee and payroll modules.
3. Employee information is stored in MySQL.
4. Payroll details are processed.
5. Salary records are viewed through the Salary Report module.
